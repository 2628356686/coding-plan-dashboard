数据采集

导入原始 curl：系统会根据接口 URL 自动识别平台类型。每个 curl 保存为独立账号，可添加备注区分。请求会保存到服务器 JSON 文件，页面每次打开或点击刷新时由服务器重新执行。注意：原始 curl 可能包含 Token/Cookie，会以明文保存在服务器。

如何复制 curl 并导入？（点击展开步骤）
  1. 用浏览器登录对应平台控制台，打开额度 / 订阅页面（以火山方舟为例：打开 Agent Plan 或 Coding Plan 额度页）
  2. 按 F12 打开开发者工具，切换到「网络 / Network」标签
  3. 刷新页面，在请求列表里找到名称包含 GetAgentPlanAFPUsage（Agent Plan）或 GetCodingPlanUsage（Coding Plan）的请求
  4. 右键该请求 →「复制」→「以 cURL (bash) 格式复制」（不要选 cmd 或 PowerShell）
  5. 粘贴到下方「原始 curl 请求」输入框，填写备注（可选），点击「保存 curl 并刷新」
注意：复制的 curl 含登录 Cookie，属敏感信息，仅保存在本地 data/ 目录；Cookie 会过期（几天到几周），过期后刷新失败时重新复制一次即可。其他平台（Codex / MiniMax / Kimi / LongCat / 千问）同理，在对应平台额度页面抓包复制 cURL (bash) 即可。
服务器仅允许已配置的域名，使用无 shell 的方式执行。

新增 Google AI 账号

填写 Antigravity / Gemini CLI 的 OAuth refresh token 创建 Google AI 账号，显示 Gemini 3.5 Flash 的用量和重置时间。refresh token 可在 ~/.gemini/antigravity-cli/antigravity-oauth-token（字段 token.refresh_token）或 ~/.gemini/oauth_creds.json 中找到。代理默认使用服务器环境变量 GOOGLE_AI_PROXY，可在此覆盖；不填则直接对外网请求。
